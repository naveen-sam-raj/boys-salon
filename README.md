# 💈 BOYS SALON — Premium Men's Grooming Lounge

A modern, responsive web application for an upscale men's barbershop and grooming studio built with **React**, **Vite**, and **Tailwind CSS**.

![Boys Salon Preview](https://images.unsplash.com/photo-1503951914875-452162b0f3f1?auto=format&fit=crop&w=1200&q=80)

## ✨ Features

- **Luxury Design & Typography**: Tailored dark-mode aesthetic with champagne/gold accents.
- **Interactive Service Catalog**: Browse services with price, duration, and category filters (Hair, Beard, Spa, VIP combos).
- **Master Barber Profiles**: Detailed bios, specialties, and customer ratings.
- **Appointment Booking Flow**: Select treatments, master barbers, dates, and time slots with instant confirmation.
- **Client Testimonials & Amenities**: Verified reviews and lounge features.
- **Mobile Responsive**: Smoothly adapts across desktops, tablets, and smartphones.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/naveen-sam-raj/boys-salon.git
   cd boys-salon
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

---

## 🌐 Live Deployment (GitHub Pages)

This repository includes an automated GitHub Actions workflow to build and deploy to GitHub Pages:
1. In your GitHub repository, go to **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, select **GitHub Actions**.
3. Push to `main`, and the website will automatically be deployed!
